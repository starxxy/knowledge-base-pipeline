# 小红书版文案（可直接复制）

**标题**

我把刷到的抖音视频，变成了一座能搜索的知识库📚

**正文**

刷到有用的教程就收藏，真正要用的时候却找不到——说的就是我本人😮‍💨

收藏只是「标记」，它不帮我记住内容，也不让我搜索里面的信息。真正有用的是文字和结论。

所以我做了一条完全跑在本地的流水线：

📎 我把链接发过去
🎬 抖音：浏览器取无水印直链 → 视频音频分轨自动合并 → GPU 转文字
📄 公众号：抓正文 + 图片自动存档
🤖 AI 提炼：一句话总结 / 核心要点 / 金句 / 标签
🗂 最后进 Markdown 知识库，还会生成一个「双击就能打开」的搜索页

实测速度⏱
· 公众号文章：3–8 秒
· 2 分钟抖音视频：约 30–40 秒（含下载 + 合并 + GPU 转写）

最爽的一点：**再也不用为了找一句话重看一遍视频**。

踩过的坑也一起开源了👇
① 浏览器会话会残留上一条视频的请求，新条目里写进了旧内容 → 现在用「页面时长校验」兜底
② 抖音 Web 是分轨的，直接下视频轨会得到没声音的 mp4 → 单独下音频轨再合并
③ 公众号会弹「环境异常」→ 换个 User-Agent 往往就好了
④ PowerShell 读无 BOM 的 UTF-8 脚本会乱码 → 中文文件显式指定编码
